## 3. いま進めている本線：ADR-0004（土台を `v51` に乗り換える）

**状態：Accepted（2026-09-20 ユーザー承認）。第1段は完了、第2段の途中。**

### なぜ乗り換えるか（EXP-20260920-29）

同じ相手・同じ seed（241〜250、各20試合）で：

| | v10（いまの提出） | **`v51`** |
|---|---|---|
| 手元27本 | 207勝63敗（76.7%） | **246勝24敗（91.1%）** |
| 上回った相手 | 5本 | 14本 |

**v10 が上回る5本はすべてコピー系**（`gods_mode`・`peak_2950`・`smaller_market_shock`・`thomas_v94_safe`・`yummers`）。
`v51` に無いのはコピー狩りだけ。本番のコピー比率32%で重み付けすると v10 80.5% / `v51` 87.3%。

### 進捗

| 段 | 内容 | 状態 |
|---|---|---|
| 第1段 | `v51` ＋ 例外時フォールバックの包み | **完了**。`submissions\v12_v51safe\`（SHA `fd3231bd…`）。preflight 全項目 OK（最悪 37.05ms）、テスト5件。**v51 原本と同じ動きであることを6試合で確認済み**。未提出 |

### 第2段の「いまここ」

- `scripts\build_v13_v51copy.py` で `submissions\v13_v51copy\main.py` を作った（SHA `641da993…`、465,168 bytes）。
  層の順番は **v51 → 判定 → 安全包み**。エントリは `_kil_safe_agent`。
- preflight は**全項目 OK**（中央値 1.03ms / 99%点 6.84ms / 最悪 37.13ms）。
- **判定の中身は `submissions\v7_relax\main.py` の候補A3 をそのまま移した**
  （96〜167 ステップで、雑草と所持金を除いた農場が一致し、所持金の差が一定ならコピー確定）。
- **やり残し：誤爆の測定とテスト。** 次の3つを確認すること。
  1. **コピー系（`gods_mode`・`peak_2950`・`smaller_market_shock`・`yummers`・`thomas_v94_safe`）で判定が出るか。**
     ※ここが重要：`v51` は v9/4 系ではないので、**コピー系相手でも農場が一致しない可能性がある**。
     一致しなければ判定は出ず、**第3段の前提が崩れる**（そのときは ADR-0004 を見直す）。
  2. **別系統（`v49`・`v50`・`v47`・`metav4_v13`・tetsutani 系・`farming_v2` など）で判定が出ないか**（誤爆）。
  3. **v12 と試合結果が1円も変わらないか**（第2段は行動を変えない設計なので、変わったらバグ）。
- 測り方：`v13` を名前空間ごと `exec` して読み込み、試合後に `_KIL_C_REPORT`（`copy_games` / `copy_turns` / `c_errors`）を読む。
  EXP-20260920-26・27 で `metav4_v13` に対してやったのと同じやり方。**スクラッチに書きかけのスクリプトがあったが残していない。**
- テストは未作成（`tests\test_v13_v51copy.py`）。`tests\test_v12_v51safe.py` と `tests\test_v7_relax.py` が雛形になる。
