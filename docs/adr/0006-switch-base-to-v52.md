# ADR-0006: 次期ベースをv12からv52へ切り替える

状態: Accepted
日付: 2026-09-21
関連: `docs/experiments/EXP-20260921-33-round7-static-analysis.md`, `docs/experiments/EXP-20260921-34-round7-runtime.md`, `docs/experiments/EXP-20260921-37-v52-base-panel.md`

## 背景

v52はv51の先頭461,510 bytesを共有し、後段に初期店舗組別の約定SELL履歴を用いるPREDICT層を追加した公開エージェントである。v12との同一seed直接比較では10勝0敗、平均+770.7±188.0円だった。

Pipe16系への全面移行はJAXAなどで致命的に退行したため不採用とした。一方、v52はv51系の土台を保持しており、21相手の回帰パネルでも必須回帰を維持した。

## 判断材料

- 初期11相手・第2回帰10相手で例外0、家畜逃走0。
- JAXA 10勝0敗、farming_v2 10勝0敗、v49 10勝0敗、v50 10勝0敗、tetsutani_dpts_b 9勝1敗。
- v12直接比較は10勝0敗、+770.7±188.0円。
- ユーザー指定`kaggriculture-more-wheat-smarter-sales`には8勝2敗、+945.8±309.8円。
- market_rhythmの新seed確認ではv52が19勝1敗、v12が16勝3敗1分で、退行は再現しなかった。
- Apache-2.0本文・帰属を確認済み。静的監査の注意0件。

## 決定案

- 次期ローカル提出候補の土台をv52へ切り替える。
- `opponents/v52/main.py`原本は変更せず、再現可能なビルドで新しい提出候補へ完全コピーする。
- v52のライセンス本文・帰属・取得元・SHA-256を保持する。
- 提出候補はpreflight、最後のcallable、依存、時間、720ターン完走、tar内容を検証する。
- 現在のv12提出枠は、Kaggle上でv52の有効性を確認するまで維持する。
- Kaggleへの提出操作はユーザーだけが行う。

## トレードオフ

v52は約1.0MBでv12より大きく、固定売却履歴への過適合可能性は残る。ただし現時点の横断評価では、v12より広範な改善があり、既存の重要な強みを失っていない。

## 実装前ゲート

2026-09-21、ユーザー承認。提出候補の生成・preflight・tar検証へ進む。Kaggleへの提出操作は行わない。

## 実装結果

`submissions/v15_v52safe/`として実装した。v52原本を先頭1,007,349 bytes完全一致で保持し、末尾に例外フォールバックだけを追加した。29テストとpreflight全項目に合格し、tar内のmain.pyも候補と完全一致した。未提出。
