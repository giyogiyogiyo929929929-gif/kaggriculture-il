# ADR-0007: 旧v52コピーだけに売却先回りを適用する

状態: Accepted
日付: 2026-09-21
関連: ADR-0006, EXP-20260919-14, EXP-20260920-30, EXP-20260921-37

## 背景

v15はv52戦略本体を採用したため、公開された旧v52またはその完全コピーとの対戦では同じ行動を選び、引き分けになりやすい。同一コード同士の対称性そのものは解消できないが、こちらだけを「旧v52を識別して先回りする派生」にすれば、現在の旧v52コピーには優位を作れる。

v53のopening signatureは、mirror-like相手では旧v52の売却ストリームへ戻す設計であり、旧v52を倒す変更にはなっていない。v6ではコピーのPREDICT売却を1ターン先回りする方式に実績がある。

## 決定

- v52原本を土台として維持し、旧v52専用の検出・先回り層だけを安全ラッパーの内側に追加する。
- step 96〜167で、雑草と所持金を除いた公開農場が一致することを要求する。
- 同期間に公開市場在庫から復元した相手の売却数量が、自分の前ターン売却数量と一致することを要求する。
- 売却一致の実イベントが3件以上なければ確定しない。1件でも不一致ならその試合では発火しない。
- 確定後だけ、旧v52のPREDICTが次ターンに出すSELLを同じ内蔵ライブラリで予測し、実行可能数量を1ターン先に出す。
- 元actionに同一商品の売買がある場合、注文枠がない場合、予測・在庫計算に失敗した場合は変更しない。
- 非対象相手ではv52と行動が完全一致することを目標とする。

## 評価ゲート

1. v52原本部分のバイト完全一致、最後のcallable、安全フォールバックをテストする。
2. 人工観測で農場一致・売却一致・最低証拠数・不一致失格・試合リセットをテストする。
3. 旧v52直接比較で両席を含め明確に勝ち越し、平均差が標準誤差の2倍以上になること。
4. v52採用時の必須回帰・第2回帰・指定Notebookで勝敗を悪化させないこと。
5. 誤発火相手を確認し、発火時の退行があれば不採用とする。
6. preflight全項目、例外0、家畜逃走0を必須とする。

## 限界

派生版同士が完全に同じコードになれば再び対称になる。席番号による非対称化や乱数化は両席平均の期待値を改善しないため採用しない。

2026-09-21、ユーザー承認。
