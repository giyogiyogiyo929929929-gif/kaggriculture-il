# ADR-0001: マクロ行動だけを模倣し、ミクロ行動はルールで実行する

状態: Superseded by ADR-0002（2026-09-19）
日付: 2026-09-18

## 背景
行動空間が構造化されており（移動・植え付け・水やり・売買・雇用など）、1試合720ターンと長い。
開発環境は GPU なしで、推論は1ターン1秒以内の制約がある。

## 決定
日単位の戦略判断（購入・売却・雇用・土地）だけを模倣モデルで予測し、移動や作業割り当てはルールベースの実行層で行う。

## 検討した他の案
- 全行動を1モデルで模倣：行動空間が大きく、CPU で学習しにくい。誤差が長いターンで蓄積しやすい。
- 模倣なしのルールベースのみ：上位勢の戦略を取り込めない（ただしフェーズ0のベースラインとして作る）。

## 結果・トレードオフ
- 学習が軽く、推論も速い。
- 上位勢の細かい作業効率は真似できない。実行層の出来が性能を左右する。
