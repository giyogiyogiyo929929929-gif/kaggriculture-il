# ADR-0004: 土台を v9/4 から v51（V47 系）に乗り換え、コピー狩りを移植する

状態: **Accepted（2026-09-20、ユーザーが承認）**
日付: 2026-09-20
関連: ADR-0003（公開エージェントを土台にする）, doc 07 §3 候補A・A2・A3, EXP-20260920-28・29, doc 06

## 背景

締め切りは **2026-10-01 09:00 JST**（残り11日）。いまの提出は v10（56392177）＝ v9/4 ＋ 候補A・A2・A3・D・E。

2026-09-20 に取り込んだ `v51`（ahmedberatozer/kaggriculture-v51-lean-flock、V47 系の後継）を
**v10 とまったく同じ相手・同じ seed（241〜250、各20試合）**で測ったところ、差がはっきり出た。

| | v10（いまの提出） | **`v51`** |
|---|---|---|
| 手元27本の合計 | 207勝 63敗（76.7%） | **246勝 24敗（91.1%）** |
| 相手ごとに上回った数 | 5本 | **14本** |

**v10 が上回る5本は、すべてコピー系**（`gods_mode` 10-0 対 5-5、`peak_2950` 10-0 対 7-3、
`smaller_market_shock` 10-0 対 7-3、`thomas_v94_safe` 10-0 対 7-3、`yummers` 10-0 対 8-2）。
**`v51` に無いのはコピー狩り（候補A・A2・A3）だけ**で、それ以外はすべて `v51` が上。

`v51` に負ける理由も分解した（EXP-20260920-29）：**生産量（植え付け235・収穫216）は同じなのに、
家畜と作物の配分が違う**。seed 242 では `v51` が家畜に 600 多く使い（羊が1頭多い）、WOOL を52個多く売って
**−5,413**。こちらは EGG で +4,899 返すが足りない。**層を足す方式（doc 07 §4）では埋まらない差**で、
生産計画は v9/4 のテープそのものに入っている。

### 本番での期待勝率（概算）

v7 の本番実績では、公開対戦69試合のうち**コピーが22試合＝32%**（EXP-20260920-19）。
手元の成績をコピー系5本とそれ以外22本に分けて、この比率で重み付けすると：

| | コピー系（32%） | それ以外（68%） | 加重した勝率 |
|---|---|---|---|
| v10 | 50勝0敗（100%） | 157勝63敗（71.4%） | **80.5%** |
| `v51` | 34勝16敗（68%） | 212勝8敗（96.4%） | **87.3%** |
| **`v51` ＋ コピー狩り（狙い）** | 100% に近づける | 96.4% | **97% 前後** |

**コピー狩りを移植できなくても `v51` 単体で v10 を上回る見込み**で、移植できればさらに大きい。

## 決定

**`v51` を新しい土台にし、コピー狩り（候補A・A2・A3 に当たるもの）を移植する。**
段階を分け、**各段階で「前の版より強い」ことを確かめてから次に進む**。

1. **第1段**：`v51` をそのまま（＋例外時フォールバックの包み）提出候補にする。
   受け入れ条件：手元27本で v10 より勝ち数が多い／preflight 全項目 OK／例外0。
2. **第2段**：コピー判定を移植する（候補A3 の判定＝96〜167 ステップで雑草と所持金を除いた農場が一致し、
   所持金の差が一定ならコピー）。**判定は土台に依存しない**ので、ほぼそのまま移せる。
   まず「判定が出たかどうか」だけを記録し、**動きは変えない**で誤爆を測る。
3. **第3段**：コピーと確定した試合だけ売りを先回りさせる。
   **`v51` の売りの仕組みに合わせて作り直す**（v9/4 の `V9_RACE_DEFAULT` 差し替えは使えない）。
   受け入れ条件：コピー系5本で v10 と同等（各20試合で勝ち越し）、それ以外で第1段から退行しない。

**どの段でも、原本 `opponents\v51\main.py` は1バイトも変えない**（doc 07 §4 と同じ作り方。末尾に層を足す）。

## 検討した他の案

- **v10 を維持する**：手元27本で 207-63。`v51` が広まると不利になる。
  `v51` は 9/20 公開で票は2だが、**v9/4 は6本、`metav4_v13` は公開翌日に2本のコピーが出ている**（EXP-20260920-28）。
  **9/23 の公開締め切りまでにコピーが増える前提で考えるべき。**
- **`metav4_v13` を土台にする**：EXP-20260920-27 で測って**見送り済み**（手元26本で 195-65 と v10 に届かない）。
- **v10 の生産計画に手を入れる**：家畜・作物の配分は v9/4 のテープの根幹で、thomas の失敗リスト
  （doc 07 §2 の事実5）に近い領域。残り11日でやるにはリスクが高い。

## 結果・トレードオフ

- **得るもの**：コピー以外の相手への勝率（71.4% → 96.4%）。手元で v10 が競っていた
  `farming_v2`・`first_in_line`・`market_rhythm`・`ready_stock`・`sunil_v8`・tetsutani 系・`v47`〜`v50` が、ほぼ全勝になる。
- **失うもの（移植できなかった場合）**：コピー系への勝率（100% → 68%）。
  本番のコピー比率が 32% なら、それでも差し引きプラス。
- **手戻りの危険**：第3段（先回り）は `v51` の売りの仕組みを読み直すところからで、
  **候補A・A2・A3 に費やしたのと同じ作業が必要**になるかもしれない。**第2段までで止める判断もあり得る。**
- **提出枠**：チームの有効枠は v10（56392177）と k256net の 56384238。
  **新しく出すと v10 が外れる**。第1段ができた時点で出すかどうかは、チームと相談して決める（doc 06）。
- **ライセンス**：`v51` は Apache-2.0 の派生で商用利用の制限なし（doc 08 §5）。
  公開されているものの利用は主催者が認めている（doc 06、#737788）。出典は層に明記する。
