# 00 概要

状態: Approved
最終更新: 2026-09-20
関連: 01_requirements.md, 08_competition_rules.md, roadmap.md

## 目的

Kaggle シミュレーションコンペ **Kaggriculture** で、リーダーボード1〜50位のチームのエピソード（リプレイ）を取得し、その行動を模倣する（Behavior Cloning）エージェントを作る。

## ゲームの要点

- 2人対戦の農場経営。720ターン（30日×24ターン）。最終所持金が多い方が勝ち。
- 作物（植え付け・水やり・施肥・収穫）、家畜（卵・牛乳・羊毛）、土地の拡張、ファームハンドの雇用、共有市場での売買。
- 詳細ルールは `kaggle_environments/envs/kaggriculture/README.md` を参照（`pip install` 後にローカルにある）。
  日本語のまとめは `docs/08_competition_rules.md`。
- **最終提出の締め切り：2026-10-01 09:00 JST（正式には 2026-09-30 23:59 UTC ＝ 10-01 08:59 JST）。** 詳細は doc 08 §0。

## スコープ

- 対象内：データ取得、パターン分析、マクロ行動の模倣、ルールベース実行層、評価、提出
- 対象外（現時点）：強化学習による自己対戦改善（roadmap のフェーズ2で検討）

## 用語集

| 用語 | 意味 |
|---|---|
| エピソード | 1試合。episodeId で識別 |
| リプレイ | エピソードの全ステップを記録した JSON |
| ダイジェスト | リプレイから学習・分析に必要な情報だけを抜いた圧縮版 |
| マクロ行動 | 日単位の戦略判断（何を買う・売る・雇う・土地を買う） |
| ミクロ行動 | ターン単位の実行（移動、どのタイルに水をやるか等） |
| 実行層 | マクロ行動をミクロ行動に落とすルールベース部分 |
| Validation Episode | 提出直後に走る、自分のコピーとの対戦 |
