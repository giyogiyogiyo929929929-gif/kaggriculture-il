# EXP-20260919-06: 「枯死25%」は計測の誤りだった

日付: 2026-09-19
関連 doc: 05_evaluation.md §2.1 / §4, 04_model_design.md §5.5, EXP-20260919-02, EXP-20260919-05
コミット: （git 未使用）

## 背景

doc 05 §4 の合格基準「枯死が植え付けの5%以下」が、初回提出から一貫して未達（約20〜25%）だった。
`tests/test_eval.py::test_baseline_loses_no_animals` も xfail のまま。
EXP-20260919-05 の試行8（枯れかけの水やりを最優先）は −292 ± 208 で効果ゼロだった。
**効果が出ないのは対策が悪いのではなく、直すべき問題が存在しないからではないか**を確かめた。

## 環境実装から確認した事実

`kaggle_environments/envs/kaggriculture/kaggriculture.py`（1.32.7）を読んだ。

1. **`PLANT → WEED` は2つの別々の原因で起きる。**
   - 水切れ：`_daily_refresh_plants`（L777-784）。日の境界で `consecutive_unwatered >= 2` なら WEED。
   - 寿命切れ：`_decay_plants`（L751-766）。`max_lifespan_step` を過ぎると2ステップごとに
     `yield_units` が1減り、0以下で WEED。
2. **`ongoing` 作物（STRAWBERRY など）は、最終収穫の翌日に必ず WEED になる。**
   `_daily_refresh_plants` L801-802 で、`production_count == max_yield` に達した時点で
   `max_lifespan_step = (next_day + 1) * turns_per_day` が設定される。**これは寿命であって失敗ではない。**
3. 一回収穫の作物（WHEAT/MELON など）は、**収穫すると `None` に戻る**（L466-467）。
   WEED になるのは収穫し損ねた場合だけ。
4. **新しく植えた作物は `consecutive_unwatered = 1` から始まる**（L222）。
   つまり**植えた当日のうちに水をやらないと、その日の境界で必ず枯れる**。
   既に定着した作物は1日なら水を抜いても死なない。

## 実測（現行 v2、3試合、seat 0）

`scratchpad/classify_weed.py` で `PLANT→WEED` を遷移直前のタイル状態で分類した。

| 分類 | 件数 | 判定 |
|---|---|---|
| 水切れによる枯死 | **0** | — |
| 未収穫のまま寿命切れ（実が残って消滅＝損失） | **0** | — |
| 収穫済みで寿命終了（`yield_units` 0、損失なし） | **33（全部 STRAWBERRY）** | 正常 |

植え付け 169 件に対し `PLANT→WEED` 33 件（19.5%）。**その全件が「全部収穫し終えたイチゴの寿命」**で、
失った実は 0。`max_lifespan_step` を過ぎてから WEED になるまでの放置ステップ数も全件 0
（＝寿命が来た瞬間に消えている＝収穫遅れではない）。

## 実測その2（本測定：20ペア×2席＝40試合、v2 対 v1）

速報が3試合・seat 0 のみだったので、`eval.py` と同じ対戦条件（seed 1〜20、席入れ替え）で数え直した。
スクリプト：`scratchpad/classify_weed_full.py`。

| 分類 | 件数 | 植え付け比 |
|---|---|---|
| 寿命終了（`yield_units` 0、損失なし） | 693 | 25.43% |
| **水切れ枯死** | **4** | **0.15%** |
| 未収穫損失（実を残して寿命切れ） | 0 | 0.00% |
| 分類不能 | 0 | 0.00% |

植え付け 2,725 件、`PLANT→WEED` 697 件。**うち 693 件（99.4%）は STRAWBERRY の寿命終了。**
水切れ枯死も STRAWBERRY が4件（速報の3試合では0件だった＝実在はするが極めて稀）。

**本当の損失は植え付けの 0.15%。合格基準（5%以下）を満たしている。**

## 結論

- **「枯死が植え付けの5%以下」という合格基準は、すでに満たされている**（実損失 4/2,725 = 0.15%）。
  未達に見えていたのは、doc 05 §2.1 の指標が **ongoing 作物の寿命を枯死として数えていた**ため。
- EXP-20260919-02 の「枯死 10/55 = 18%」、EXP-20260919-05 の「17/68 ≒ 25%」も同じ誤りを含む。
  これらの数値は**取り消す**（各文書に注記を入れる）。
- 試行8（枯れかけの水やり最優先）が無効だった理由も説明がつく。
  直せる対象が40試合で4件しかなく、金額差に出ようがなかった。

## 指標の定義をどう直すか（doc 05 §2.1 の変更案）

`PLANT→WEED` を1つに丸めず、遷移直前のタイル状態で3つに分ける。

| 指標 | 条件（遷移直前のタイル） | 意味 |
|---|---|---|
| **水切れ枯死** | `watered_today` が False かつ `consecutive_unwatered >= 1` | 水やりの失敗 |
| **未収穫損失** | 寿命切れ かつ `yield_units > 0` | 収穫の失敗（実を捨てた） |
| 寿命終了 | 寿命切れ かつ `yield_units <= 0` | 正常。**指標から除外する** |

合格基準（doc 05 §4）は「**水切れ枯死 ＋ 未収穫損失 が植え付けの5%以下**」に置き換える。
