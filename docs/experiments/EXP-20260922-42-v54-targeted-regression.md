# EXP-20260922-42: v54重要10相手の省資源回帰

状態: Implemented
最終更新: 2026-09-22
関連: EXP-20260922-39、EXP-20260922-41、docs/05_evaluation.md

## 目的

上位代表6本でv54が30勝0敗だったため、v22の既存回帰パネルから系統の異なる重要10本を
選び、全面ベース候補として大きな退行がないか低コストで確認する。

## 方法

- 対象: v49、v50、metav4_v13、k256_h2_q_v1、market_rhythm、story_of_seasons、
  thomas_router_93、tetsutani_dpts_b、jaxa_2802、ready_stock。
- v22既存結果と同じ相手別seed開始値を使い、各5ペア・両席・並列4で評価する。
- v22側は既存10ペアJSONの先頭5ペアを再利用し、追加CPUを使わない。
- 例外・家畜逃走・明確な勝敗退行がなければ、残りパネルまたは提出用安全化へ進む。
- monitor JSONへ相手ごとの完了を記録する。提出は行わない。
