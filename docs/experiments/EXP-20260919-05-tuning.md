## 仮説

EXP-20260919-04 の「day 3〜12 に資金が尽きて家畜も土地も増やせない」を解消すれば、
公開対戦のレート（509）が上がる。

## 方法

`scripts\eval.py <候補> baselines\v1_agent.py -n 20 -j 4` で、提出版（v1）に対するペア差を測る。
判定は doc 05 §4：**ペア差の平均が標準誤差の2倍以上**。

## 測定方法の欠陥を1つ直した（重要）

試行7・8 が「差0・全ペア引き分け」になったのは改善が無かったからではなく、
**比較方法が壊れていた**ため。当初の凍結版（`baselines\v1_agent.py`）は
**パラメータだけを固定し、コードは現行の `agent/` を共有**していた。
そのため `macro.py` / `execute.py` の**コード変更は両者に同時に効き、差が出ない**。

→ `scripts\freeze_agent.py` を作り、**パッケージ名を変えてコードごと写す**ようにした
（`baselines\v2_pkg\` など）。凍結し直した v1 と v2 で +14,029 ± 1,402 が再現することを確認済み。
試行7・8 は凍結し直したうえで測り直している（上の表はその結果）。

## 上位勢との行動内訳の比較（新しい発見）

自分の公開対戦23席と、上位20位以内の165席で、1席あたりの行動を比べた。

| 指標 | 自分（v1） | 上位20位以内 |
|---|---|---|
| 総行動数/席 | 7,240 | 7,206（ほぼ同じ＝雇用数は同等） |
| **PASS** | **1,632回（22.5%）** | 548回（7.6%） |
| 移動 | 53.7% | 43.3% |
| WATER | 729 | **1,129** |
| HARVEST | 207 | **485** |
| PLANT | 78 | **244** |
| CARE | 166 | 326 |
| COLLECT_FERTILIZER | 163 | 385 |

**雇っている人数は同じなのに、有効な行動が上位の半分以下。全行動の22.5%が PASS（＝やる仕事が無い）。**
空きタイルが余っているのに植えるものが無い、家畜が少ない、という状態が続いている。

ただし「種を増やして畑を埋める」（試行9・10）は**金額では改善しなかった**。
WHEAT は種10で4〜6個（約39/個）と、STRAWBERRY（種100で4個×約156）に比べて割に合わない。
**仕事の量を増やすのではなく、単価の高い仕事を増やす**方向で探すべき。
