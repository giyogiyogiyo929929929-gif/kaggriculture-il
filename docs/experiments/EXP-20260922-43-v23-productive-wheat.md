# EXP-20260922-43: v22への一時WHEAT周期の独立移植

状態: Implemented
最終更新: 2026-09-22
関連: EXP-20260922-40、EXP-20260922-42、ADR-0007

## 目的

ユーザー承認に基づき、全面ベースとして不採用になったv54から、一時WHEAT周期だけをv22へ
独立移植する。v54の成熟延期と価格31未満の売却ガードは混ぜず、効果を分離する。

## 仕様

- v22の全バイトを先頭に保持し、末尾ラッパーとして追加する。
- route 0の先頭96ターンだけを毎エピソード開始時に原状復帰してから変更する。
- step 0でWHEAT種を1個追加購入する。
- 空いているhand 1をstep 2〜6に西へ3回、WHEAT植付け、散水へ使う。
- step 29はhand 2のPASTURE建設を散水へ置換する。
- hand 0をstep 49〜57に散水、収穫、PASTURE復旧、shed帰還へ使う。
- v22の旧v52コピー検出・BRUNCHガード・安全フォールバックはそのまま親として呼ぶ。
- routeの反復変更や複数席による種購入の重複を防ぐため、保存した原状から毎回構築する。

## 受け入れ条件

1. v23の先頭がv22と完全一致する。
2. 上記以外の先頭96ターンのroute 0が変わらず、market注文数10以下を維持する。
3. 同じエピソードを両席で呼んでもWHEAT種追加が1注文だけになる。
4. 専用テスト、静的監査、preflightに合格する。
5. まずv54で改善した上位代表6本を同seedスモークし、改善が再現した場合だけ重要10相手回帰へ進む。
6. 例外、家畜逃走、またはv22から明確な勝敗退行があれば不採用。

## 結果

`submissions/v23_productive_wheat/main.py`を再現ビルドした。v22先頭保持、静的監査注意0件、
専用テスト8件、preflight全項目に合格（中央値1.29ms、p99 6.55ms、最悪57.75ms）。
SHA-256は`d17bb01dba90a519a2753c6d0399a7c6bbf76ff7ba45863e76272ec0e3714d1b`。

上位代表6本の5ペアゲートは全相手0勝5敗、平均差約-101,000〜-108,000円、v23側の
家畜逃走3となり不合格。重要10相手回帰は自動停止し、実行していない。v23は不採用。

seed 601を追加診断すると、一時WHEATは植付け済み、2個収穫、PASTURE復旧、shedへの配送まで
すべて成功し、拡張例外0だった。それでも最終差は-77,840円。したがって単純な座標・命令ミス
ではなく、序盤の追加購入・route変更がv22の後続する家畜・作物判断を大きく分岐させる
状態依存カスケードが原因。v54の親系統で安全だったroute変更をv22へそのまま移植できない。

結論としてv22を維持し、一時WHEAT移植案は棄却する。提出物は作成せず、Kaggle未提出。
