# EXP-20260922-49: v22のPublic scoreと公開対戦を分析する

状態: Approved / 評価完了
最終更新: 2026-09-22
関連: EXP-20260921-38、EXP-20260922-46、EXP-20260922-47

## 目的

提出済みv22（submission `56439885`）の現在のPublic scoreと直近公開対戦を確認し、
勝敗を店舗構成、相手、売却競合、農場分岐に分解する。Kaggleへの新規提出は行わない。

## スコア

解析開始時のPublic scoreは `2226.3`、完了後の再確認では `2230.3`。比較対象のv12
（submission `56398792`）は開始時 `2371.0` で、再確認時点のv22は140.7低い。ただし対戦相手と
試合数が異なるレーティングなので、差だけで
実装の優劣を断定せず、直近24戦のリプレイを同じ集計器で分析する。

## 方法

- Kaggle公式CLIからv22の直近24公開リプレイを取得する。
- v12分析（EXP-46）と同じ集計器で勝敗、最終差、店舗、物理コピー継続、SELL競合、
  相手の最終構成を抽出する。
- 生リプレイは今後のfingerprint・台帳分析に再利用できるため削除しない。
- バックグラウンドrunnerと独立watcherを同時に起動し、監視JSONで完了を確認する。

## 結果

3本の監視runner（リプレイ取得・早期YARN台帳・全敗戦台帳）と敗戦fingerprintはすべて完走し、
独立watcherも全処理の `complete` を確認した。

### 直近24戦

| 区分 | 勝敗 | 平均差 |
|---|---:|---:|
| 全24戦 | 12-12 | +12.8円 |
| 古い12戦 | 7-5 | +319.6円 |
| 最新12戦 | 5-7 | -293.9円 |
| 最初の2店舗にYARNあり | 1-5 | -651.7円 |

| 167 step超まで物理コピー | 11-4 | +662.8円 |

席0は7-9・平均-16.6円、席1は5-3・平均+71.6円であり、主要因を説明するほどの席差ではない。
最新12戦が悪化しており、Public score 2230.3は直近の相手構成に対してv22が安定して勝ち越せて
いない状況と整合する。

### 売買台帳

12敗の最終差合計は-13,827円。売上差は合計-11,070円、追加支出差は-2,757円だった。

| 項目 | v22−相手 |
|---|---:|
| EGG売上 | -4,405円 |
| MELON売上 | -3,300円 |
| STRAWBERRY売上 | -3,062円 |
| FERTILIZER売上 | -1,529円 |
| MILK売上 | -1,133円 |
| WHEAT売上 | -575円 |
| CARROT売上 | +1,235円 |
| WOOL売上 | +1,699円 |
| 余分なWHEAT購入支出 | -1,662円 |

WOOLは敗戦全体でもプラスなので、v22の先回り対策自体は機能している。問題は別商品へ移った。
コピー近縁4敗ではWHEAT売上が+1,441円でも購入支出が1,735円多く、MILK、STRAWBERRY、
FERTILIZER、WOOLの小差が重なった。序盤分岐8敗ではEGG -4,405円、MELON -3,187円、
STRAWBERRY -2,506円、WHEAT -2,016円が中心で、生産構成から異なるため単純なSELL順序だけでは
直らない。

早期YARN 5敗に限ると、WOOL売上差は合計-275円に縮小した。一方、STRAWBERRY -2,452円、
FERTILIZER -1,281円、MILK -940円、余分なWHEAT購入2,718円が残った。EXP-47でv25に対して
見つけた課題と同じで、WOOL対策後の次のボトルネックは終盤WHEAT購入と他商品の売却である。

### 敗戦相手の系統照合

主要公開10候補へ88試合を逐次照合し、12敗中3敗を完全一致で同定した。

- `jorge fabian avila`、`hidsaito`: More Wheat完全一致。
- `PLReddy23`: V56とpipe18がこのseedで同一結果となり両方に完全一致。
- 残る9相手: v49、v52/v53、v54、V56、More Wheat、pipe16/18、story、JAXAの今回の候補版には
  完全一致せず、新しい派生または別系統。

V56/pipe18とMore Wheatへの手元での弱さがPublic戦でも3敗として現れた。ただし全面ベース化は
EXP-44/48でJAXAへの0-5と家畜逃走を確認済みなので採用しない。

## 判断

- Public scoreだけでv22を直ちに破棄はしないが、最新12戦5-7と異系統1-8から、現環境の提出候補
  としてはv25を優先する。
- v22のBRUNCH guard・先回り層は保持する。WOOL対策を強める方向は優先しない。
- 次の改善対象は、コピー近縁では終盤の余分なWHEAT購入、異系統ではEGG/MELON/STRAWBERRYの
  生産・売却差。ただしV56/More Wheat全面移植ではなく、発火条件を分離した小層で検証する。
- 生リプレイ24本と台帳はfingerprint・再現に使えるため保持する。Kaggleへの提出は行っていない。
