# EXP-20260922-45: V56のE402/E410だけをv22へ分離移植

状態: Approved / v25提出候補
最終更新: 2026-09-22
関連: EXP-20260922-44、ADR-0007

## 仮説

V56全体はJAXAへ0-5のため採用しない。一方、末尾のE402（終盤の余剰WHEAT/CARROT種購入抑制）と
E410（収穫量を増やさない肥料投入抑制）は、既存方策を大きく変えない独立した節約層である。
これらだけならv22の異系統耐性を保ったまま終盤現金を改善できる可能性がある。

## 候補

- v24: v22 + E402のみ。
- v25: v22 + E402 + E410。
- 移植元: Ahmed Berat Ozer, `kaggriculture-v56-smarter-seeds-and-fertilizer`（Apache-2.0）。

両候補とも静的監査0警告、構文確認、preflight全項目合格。最悪推論時間はv24 38.79ms、
v25 41.29ms。

## 評価

同一seedでv22との直戦、v25対v24の層間比較を各10ペア行う。その後、JAXA、v49、v52へ
各5ペアを順次実行する。例外と家畜逃走も監視し、Kaggle提出は行わない。
