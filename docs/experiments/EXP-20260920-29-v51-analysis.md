# EXP-20260920-29: v51 に負ける理由の分解と、v51 の手元での強さ

日付: 2026-09-20
関連 doc: 07 §3 候補D・候補E, ADR-0004（土台の乗り換え）, EXP-20260920-28（取り込み）, 05 §8
コミット: 未コミット（`scripts\analysis\money_trace.py` を追加）

## 仮説

`v51`（ahmedberatozer/kaggriculture-v51-lean-flock、9/20 公開）に v10 が 3勝7敗。
`metav4_v13` のときと同じく「売り方の差」なら、候補D・E の延長で埋められるはず。

## 方法

1. `scripts\analysis\money_trace.py`（今回作った。日ごと／ステップごとの所持金差）で、差がどこで開くかを見る。
2. `scripts\analysis\ledger_match.py` ＋ `ledger_report.py`（**約定1個ずつの台帳**）で、品目ごとの売上と支出を比べる。
   ★注文の数量は在庫でクリップされるので、**注文から集計してはいけない**（今回いったん間違えて、台帳に切り替えた）。
3. `v51` を手元27本と対戦させ、v10 と同じ相手・同じ seed で比べる。

## 結果1：生産量は同じなのに、作るものの配分が違う

`eval.py` の健全性：**両者とも植え付け 235・収穫 216・損失1・家畜逃走0**（seed 241〜250）。

台帳での分解（v10 − `v51`）：

| seed | 結果 | 主な差 |
|---|---|---|
| 242 | −2,245 | **WOOL −5,413**（v10 157個@133 / `v51` **209個@126**）、EGG +4,899（v10 159個@60 / `v51` 77個@59）、**家畜の支出 6,900 / 7,500** |
| 246 | −1,941 | **CARROT −4,952**（v10 173個@65 / `v51` 243個@67）、WHEAT +2,337 |
| 250 | +1,032（勝ち） | WHEAT +1,910、STRAWBERRY +1,072、CARROT −1,915 |

- **負けた試合の合計は WOOL −5,230・CARROT −4,866 が二大要因。** 勝った試合でも CARROT −1,915 と押されている。
- seed 242 で `v51` は**家畜に 600 多く使っている**（羊が1頭多い）。ノートブック名の「**lean flock**（絞った群れ）」どおり、
  **家畜構成の最適化**が売りの版。WOOL を52個多く売り、こちらは EGG で返すが足りない。

→ **これは「売り方」ではなく「何を作るか」の差。** `metav4_v13` のとき（生産も売る量も同じで、順序と時刻だけが違う）とは別物で、
**末尾に層を足す方式では埋まらない**。生産計画は v9/4 のテープそのものに入っている。

## 結果2：`v51` は手元27本に対して圧倒的に強い

v10 とまったく同じ相手・同じ seed（241〜250、各20試合）：

| | v10 | **`v51`** |
|---|---|---|
| 合計 | 207勝 63敗（76.7%） | **246勝 24敗（91.1%）** |
| 相手ごとに上回った数 | 5本 | **14本** |

**v10 が上回る5本はすべてコピー系**：

| 相手 | v10 | `v51` |
|---|---|---|
| `gods_mode` | 10-0 | 5-5 |
| `peak_2950` | 10-0 | 7-3 |
| `smaller_market_shock` | 10-0 | 7-3 |
| `thomas_v94_safe`（v9/4 原本） | 10-0 | 7-3 |
| `yummers` | 10-0 | 8-2 |

`v51` が上回る14本：`farming_v2`・`first_in_line`・`market_rhythm`・`ready_stock`・`sunil_v8`・
`tetsutani_ms`・`tetsutani_dpts`・`tetsutani_dpts_b`・`jaxa_2802`・`shop_router_v7`・`v46`・`v47`・`v49`・`v50`
（多くが 10-0 または 9-1）。`metav4_v13` には両者とも 5-5。

## 分かったこと

1. **`v51` に無いのはコピー狩りだけ。** それ以外はすべて `v51` が上。
2. **本番のコピー比率は 32%**（v7 の公開69試合中22試合。EXP-20260920-19）。
   手元の成績をこの比率で重み付けすると、**v10 80.5% に対し `v51` 87.3%**。
   コピー狩りを移植できれば 97% 前後を狙える。
3. → **ADR-0004（土台を `v51` に乗り換え、コピー狩りを移植する）を Proposed で書いた。ユーザーの承認待ち。**
