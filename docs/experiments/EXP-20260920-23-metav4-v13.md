## 考察

1. **これは手元で v7 がはっきり負け越す初めての公開エージェント。**
   それまでは手元58本に通算 1,126勝74敗（EXP-20260920-20）。59本目にして初の明確な負け越し相手。
2. **v9/4 系の改造では届いていない。** v4 → v7 で +336、v7 → v8（候補D）でさらに +95 改善するが、
   どれも −900 前後の負け越し。**土台ごと不利**になっている可能性がある。
3. **相手はこちらの「コピー狩り」を承知で作られているとみてよい。** 作者が v9/4 本人で、名前が「Metav4」。
   判定窓（96〜167）では完全にコピーとして振る舞い、**その後で上を行く**形になっている。
   候補A3 が発火しても負けるということは、**先回りした売りの上をもう一度取られている**と考えられる。
4. **最終トーナメントへの影響が大きい。** 公開ノートブックの共有期限は 9/23 23:59 UTC（doc 06）で、
   このノートは 9/20 に出たばかり。**締め切りまでにコピーが広まると、v7 の強みが逆に狩られる。**
   ただし票数は取得時 11 で、まだ広まってはいない。

## 追加調査1：metav4_v13 の層を読む（2026-09-20、ソースの読み取りのみ）

層の構成は **v9/4 と同じ並び**（`_SHOP` → … → `_V9_RACE` → `_V9_RACEPX` → `_V9_RACEGATE` → `_CA` → `_OR2` → `_CH` → `_SR` → `_HD2` → `_CS`）で、
**v9/4 には無い層がその後ろに5つ積んである**（行番号は `opponents\metav4_v13\main.py`）。

| 行 | 層 | 中身（コメントとコードから） |
|---|---|---|
| 5762〜 | **`_RACE`（EXP283 adaptive arm）** | 「**clone-gated sale pre-emption with drop-time race escalation**」。相手が自分と同じテープを実行していると見たら horizon 8 で予約（`_RACE_HORIZON_CLONE=8`）。さらに「**自分の shed に品物が落ちたそのターンに、相手が同じ品を売った**」（＝先回りされた）のを観測すると、**残り試合ずっと horizon 24 に上げる**（`_RACE_HORIZON_ESCALATED=24`、`_RACE_HORIZON_MIRROR=24`） |
| 5884〜 | `_R127` | 売りの優先順位と最終時刻の調整 |

## 追加調査2：負け方の分解（seed 17 ＝ 最大の負け −3,192、seed 9 ＝ 最大の勝ち +1,823）

所持金の差がどのステップで開くかを追った（約定量は注文の数量と違うので、**所持金の増分で測った**）。

- **d00〜d11 は差がぴったり 0。** 差が開くのは **d12 以降、とくに d16・d23・d25・d26・d28**（seed 17 は d28 で −1,186、d16 で −931）。
- **生産量は同じ**（`eval.py` の健全性：両者とも植え付け 238 → 収穫 217、損失1、家畜逃走0）。
  → **負けているのは作る量ではなく、終盤の「売り方」だけ。**
- 同じターンに同じ品を売っていて、**順序と1回の量だけが違う**場面が実際にある（seed 17・step 602）：

  | | v7 | metav4_v13 |
  |---|---|---|
  | step 602（d25 h02） | `MILK x9 @252` → `WHEAT x11 @38` | **`WHEAT x11 @38` → `MILK x2 @252`** |

  これが `_v44y_reorder`（並べ替え）と、1回に売る量を絞る動きの実物。売ると値が下がるので、**順序と分割で手取りが変わる**。
- 終盤（d28 h18〜h20）では、v7 が `WHEAT x1000 / CARROT x1000`（在庫を全部投げる形の注文）を出す一方、
  metav4 は売らずに待ち、次のターンに `MILK x8 @270` を取っている。

### 勝った試合（seed 9）で何が起きたか

- ここでも d00〜d13 は差 0。**v7 は d20 で +781、d26 で +529、d28 で +418** と、終盤に取り返して勝っている。
- step 500（d20 h20）で v7 は `MILK x2 @9` と `STRAWBERRY x4 @147` を同時に出し、metav4 は `STRAWBERRY x4 @147` だけ。
  **v7 の候補A（先回り）が先に高値の枠を取った場面**で、この1ターンで +1,108。
- つまり **v7 が勝つのは「先回りが刺さったとき」だけ**で、相手の並べ替えが効く通常のターンでは少しずつ負ける。
  16 seed で判定が発火して4勝12敗という数字と符合する。
