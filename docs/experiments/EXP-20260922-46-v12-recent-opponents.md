# EXP-20260922-46: v12公開対戦から最近の相手特徴を抽出

状態: Implemented
最終更新: 2026-09-22
関連: docs/05_evaluation.md §8、EXP-20260920-31

## 目的

submission `56398792`（v12）の直近公開対戦から、最近投入されたエージェントの実戦上の特徴を探す。
公開コードの推測ではなく、Kaggle公式リプレイに記録された行動を根拠にする。

## 対象と方法

- 直近24件の公開エピソード（Validationは除外）。
- 相手名、勝敗、席、最初の農場分岐、step 167までの物理農場一致、売買・作業行動、
  同品目売却の同時衝突、相手がv12より1〜2ターン先に売る回数、日別資金差、終盤の農場構成を抽出する。
- 相手名別と全体の両方で集計し、勝ち試合と負け試合をともに分析する。
- 生リプレイは今後の再解析に使えるため削除しない。
- 取得と解析は一つの監視付きrunnerで連続実行し、monitor JSONへ完了・失敗を記録する。
- 早期YARN系がまとまって弱点になった場合は、その試合だけを既知の主要公開版と同一seed・同一席で
  再現し、最終所持金が1円単位で一致する版を指紋照合する。

## 結果

### 全体

- 対象期間は2026-09-21 13:14〜18:57 UTC、24試合、相手名は23種類。
- v12は10勝14敗、平均差-252.6円。最新8試合は2勝6敗、平均-636.4円だった。ただし
  対戦相手と席は無作為に均されていないため、時系列悪化の断定には使わない。
- 席0は9勝7敗・平均+76.1円、席1は1勝7敗・平均-910.0円。強い席依存の疑いがあるが、
  相手強度との交絡があるため同一相手・両席で再確認が必要。
- step 167まで物理農場が一致した相手は8/24。成績は4勝4敗、平均+244円であり、
  「長く同じ農場＝脅威」だけでは最近の負けを説明できない。
- 22/24相手はstep 1から市場注文がv12と異なる。一方、物理農場一致8件を含むため、最近の差分は
  農場ルートより市場制御へ先に現れる。

### 最大の特徴: 早期YARN系

最初の2店舗に`YARN_STORE`を含む5試合は0勝5敗、平均-2,255.4円。その他17試合は
8勝9敗、平均+87.3円、`BRUNCH_SPOT/BRUNCH_SPOT`の2試合は2勝0敗、平均+1,865円だった。

早期YARNの5相手はすべて最終的に概ね6牛・11羊・11人・3区画へ収束する。ただしv12側も
同じ構成にほぼ収束しており、単なる羊頭数差ではない。70回の同一seed・同一席指紋照合では、
次の公開系統と最終所持金が両者とも1円単位で一致した。

| 本番の相手名 | 一致した手元版 |
|---|---|
| 姜上（Integ） | pipe16 |
| fishwg | story_of_seasons、metav4_v13（このworldでは同額） |
| Irabala | v54 |
| MoZayed | v52、v53（このworldでは同額） |
| HY ISHI | 主要14候補に完全一致なし |

別名の参加者が、Pipe16/v52〜v54/Story/Metav4近縁の公開上位系統を実戦投入している。
HY ISHIも6牛・11羊型だが、既知版からさらに変更された派生とみられる（行動類似からの推定）。

### 早期YARNの金額差

5試合を本番行動のまま台帳再生し、全件で最終所持金の完全一致を確認した。v12から見た5試合合計の
売上差は、WOOL -14,745円、WHEAT -4,687円、MILK -1,485円が主なマイナス。CARROT
+1,932円、FERTILIZER +2,867円では埋められない。

- WOOLは販売数量が平均で相手より約4個少ないだけだが、平均販売単価が相手より約9.8円低い。
  **最大要因は羊の数ではなくWOOLの売り時。**
- v12は相手よりWHEAT購入費を合計7,573円抑えている一方、肥料購入費は3,079円多い。
  節約だけではWOOL/WHEAT売上の悪化を補えていない。
- 相手の「v12より1〜2ターン先の売却注文量」は負け試合平均483、勝ち試合平均719で、単純な
  先回り回数は勝敗と逆相関だった。数量は注文値で約定量ではなく、過大注文も含むため、
  **全商品を一律に先回りする対策は根拠が弱い。WOOLの価格条件へ限定すべき。**

### その他の特徴

- WHEAT売却注文が1万単位になる過大注文型は6/24、v12は4勝2敗・平均+545円。
  これは市場在庫でクリップされる予約的注文の署名だが、単独では脅威ではない。
- 4区画または13人まで拡張する型は5試合で1勝4敗、平均-680.6円。早期YARNほど強くないが
  次点の注意系統。
- 最近8試合だけでは2勝6敗だが、早期YARN、拡張型、席の偏りが混ざっており、単純な
  「時間とともに全員が強化された」という結論にはしない。

## 次のアクション

v25を早期YARNの既知4系統（pipe16、story/metav4、v54、v52）へ本番と同じseed・席で当て、
WOOL売上単価と勝敗をv12から比較する。対策を作る場合は全品目の先回りではなく、早期YARN時の
WOOL売却条件だけを候補にする。
