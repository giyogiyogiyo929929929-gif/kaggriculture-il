## 仮説

上位勢の「いつ・何を・どれだけ」買う／売る／雇うには共通の型があり、それをルール化すれば
ベースラインになる。また、勝ち席と負け席ではマクロ行動に差が出るはず。

- データ：上位50チーム × 各5エピソード → 重複除去して **207エピソード / 414席**（`data\digest\*.json.gz`）
  - 取得日 2026-09-18、Validation Episode は除外済み（02 §3）
  - 順位が付いた席 344 / 414（残り70席は50位圏外の相手）

  - 集計規模：daily_orders 100,341行 / prices 55,890行 / daily_state 12,420行

## 考察

- **序盤〜終盤の「型」はきれいに揃っており、ルールベース化できる**（0-6 の初期パラメータは §2 の数字をそのまま使える）。
  特に「初日に全額投資 → MELON で day10 に一気に資金化 → STRAWBERRY + 家畜の定常運用 → 終盤 CARROT」は明確。
- **一方で、マクロ行動だけでは勝敗が説明できない。** 上位50チーム同士の対戦は戦略がほぼ同型で、
  差は実行効率（ファームハンドの動かし方、水やり・収穫の取りこぼし）や市場タイミングの細部にあると考えられる。
  ミクロ行動が総行動数の大半である事実とも整合する。
- これは ADR-0001（マクロだけ模倣し、ミクロはルール実行）の前提に関わる。**マクロ模倣の価値は
  「上位の型を最短で再現すること」であって、そこから先の伸びは実行層の質で決まる**と考えるべき。
  フェーズ1の評価で差が出なければ、ADR-0001 を見直す新しい ADR を書く。
- 注意：今回のサンプルは上位50チーム同士の対戦に偏っている。弱い相手との対戦が入れば
  マクロ行動の差はもっと出るはずで、「マクロに意味がない」という結論ではない。
