# EXP-20260922-40: v54追加層のアブレーション

状態: Implemented
最終更新: 2026-09-22
関連: EXP-20260922-39、ADR-0007、docs/05_evaluation.md

## 目的

上位公開ノートv54との10ペアが5勝5敗だったため、v54末尾の追加層を分離し、どの変更が
v22との差を作るか確認する。提出やv22の変更は行わない。

## 確認済みの層

1. `opening`: day 0にWHEAT種を追加し、一時WHEATをday 2に回収・販売する。
2. `mature`: 一時WHEATの回収をday 3まで遅らせ、成熟量を増やす。
3. `guard`: step 91のWHEAT価格が31未満なら、その時点のWHEAT売却を取り除く。

公開ノートブックのセルは実行せず、静的抽出済み`main.py`を各層の公開境界で機械的に
切り出す。切り出し後も静的監査を行う。

## 方法

- `opening`と`mature`をv22に対し、最終v54と同じseed 701〜710・10ペア・両席で評価する。
- 最終v54の既存結果と比較し、勝敗・平均差・seed別差を確認する。
- バックグラウンド評価はmonitor JSONを各段の終了時に更新する。
- 例外または家畜逃走が出た層は採用候補にしない。

## 結果

- `opening`: v22が6勝4敗、+116.7±343.2円。
- `mature`: v22が6勝4敗、+89.1±343.7円。
- `guard`込み最終v54: 5勝5敗、+61.7±343.1円。
- 例外0、v22の家畜逃走0。

成熟延期は全10 seedでv54を18〜40円改善し、価格ガードも全10 seedで24〜41円改善した。
平均では各層が約28円ずつv54を強化した。seed 704はv22側の差が+58円→+18円→-7円となり、
価格ガード追加で唯一勝敗が反転した。両層とも効果方向は安定しているが小さく、差は標準誤差
より大幅に小さい。単独でv22へ移植するより、最終v54を別ベース候補として同じ上位相手に
当て、総合退行がないか確認する。
