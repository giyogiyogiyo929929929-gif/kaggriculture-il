For each SELL item:

```python

later = sum(price(item, inventory + qty + j) for j in range(qty))
self_exposure = now - later
```

- `288 <= step < 694`
- the action/order list is non-empty
- the first order is SELL
- only the contiguous leading SELL prefix is touched
- at least 5 distinct SELL items are present
